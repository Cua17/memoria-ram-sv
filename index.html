De transistores a RAM, capa por capa

  1. AND-OR latch — celda de 1 bit, pura realimentación de compuertas (sin reloj).
  2. Gated latch + registro — una sola línea de datos + write enable; varios latches con el mismo write enable.
  3. Decodificador — N bits de dirección → 2^N salidas one-hot.
  4. Celda direccionable + bus triestado — una sola línea inout sirve para leer y escribir.
  5. Matriz — decodificador de fila + de columna, filtrado con AND, para direccionar una celda entre muchas.
  6. mem_top — una matriz por bit de la palabra, compartiendo dirección y control: la RAM como lista de bytes.
